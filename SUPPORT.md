# Support

This project is shared as a reference sample. It is not actively maintained, and there is no guaranteed response time. Support is best-effort through [GitHub Issues](../../issues), so please do not expect a fast turnaround.

## Questions

Review the [README](README.md) and linked Cloudflare documentation first. If behavior remains unclear, open an issue with the question, your Wrangler version, and sanitized configuration.

## Bugs

Use the [bug report template](../../issues/new?template=bug_report.md) and include reproducible steps. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of filing a public issue.

## Gallery Removal And Abuse Reports

To withdraw or report an example in the hosted demo's gallery, use the [removal request template](../../issues/new?template=removal_request.md) and name the example's title. Issues are public, so do not attach the image or personal details. The operator unpublishes the example and purges its cached copies. Private results never appear in the gallery and expire after 24 hours.

## Platform Support

For Cloudflare product support or behavior outside this reference implementation, use the support options associated with your Cloudflare account or the official [Cloudflare developer community](https://community.cloudflare.com/).
